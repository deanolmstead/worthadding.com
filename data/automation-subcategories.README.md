# Automation Subcategories

`automation-subcategories.txt` is the allowed topic universe for the daily Worth Adding comparison automation.

Selection rules:

- Build one comparison per day.
- Pick one subcategory from the list, then choose two directly comparable products inside that subcategory.
- Prefer low-risk, sourceable categories with official specifications, stable model names, and clear buyer intent.
- Skip or defer categories where a useful comparison would require medical claims, safety advice, regulated advice, live pricing, restricted review data, or hard-to-verify compatibility.
- Do not repeat an existing Worth Adding comparison pair.
- If the chosen subcategory is too broad, narrow it to a shopper-real product type before selecting products.
- If no clean product pair is available in the chosen subcategory, choose a different listed subcategory and explain the deferral in the final run summary.
