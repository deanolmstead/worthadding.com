Buyer guide

Choose by tape width and workflow.

The right CUBE depends less on brand and more on the labels you actually plan to make: narrow mobile labels, wider visible labels, repeated copies, or computer-designed layouts.

P-touch CUBE Plus

Buy this if / skip this if

Buy this if
  • You want 18mm or 24mm labels for bins, shelves, retail tags, craft packaging, or anything viewed from a distance.
  • You plan to design labels on a computer with P-touch Editor, not just on a phone.
  • You print repeated labels and want automatic cutting instead of manually cutting each one.
Skip this if
  • You only need simple 12mm household labels and will never use wider tape.
  • You prefer replaceable AAA batteries over charging an internal battery.
  • You want the smallest cube body for moving between rooms and drawers.
P-touch CUBE

Buy this if / skip this if

Buy this if
  • Your labels are mostly 12mm and smaller: pantry bins, file folders, toy bins, notebooks, and drawers.
  • You want a mobile-app label maker without desktop software or USB setup.
  • You value the smaller body and simple manual cutter more than batch-print convenience.
Skip this if
  • You need larger labels that stay readable on shelves, boxes, or shop displays.
  • You will print many copies in a row and do not want to use a manual cutter.
  • You want the built-in rechargeable battery and USB cable package included with the Plus model.
24mm tape changes the job

12mm labels work for close-up organization. 18mm and 24mm labels are easier to read on bins, drawers, shelves, craft packaging, and shared work areas, which is the clearest reason to choose Plus.

Automatic cutting matters in batches

A manual cutter is fine for a few pantry labels. If you make dozens of file, inventory, classroom, or craft labels at once, the Plus model's automatic cutter removes a small but repeated interruption.

Desktop software is the ownership split

P-touch CUBE Plus can sit in a computer workflow through USB and P-touch Editor. The standard CUBE is better treated as a phone-first appliance for quick labels around the house.

Before you buy

Check tape width, power, and app expectations first.

  • Pick the label width before the machine. If you may need 18mm or 24mm, skip the 12mm-only model.
  • Budget for tape refills. Both models use Brother TZe tapes, and the cartridge type matters more than the printer shape.
  • Confirm the app/software path you want. Plus supports mobile apps and desktop P-touch Editor; the basic CUBE is mainly mobile app-driven.
  • Decide how you want power handled: built-in rechargeable battery and USB cable on Plus, or AAA batteries/AC adapter on CUBE.

FAQ

Questions before checkout.

Which Brother P-touch CUBE is better for most people?

P-touch CUBE Plus is the better default if you want 24mm tapes, automatic cutting, USB desktop use, a built-in rechargeable battery, and more software options. P-touch CUBE is the simpler pick for mobile-only 12mm home labels.

Do both label makers use the same tape family?

Yes. Brother lists the TZe tape family for both models, but the supported width is different: up to 24mm on P-touch CUBE Plus and up to 12mm on P-touch CUBE.

Which one is better for computer-created labels?

P-touch CUBE Plus is the better fit because Brother lists USB 2.0 Full Speed for Windows and Mac plus P-touch Editor support. P-touch CUBE is primarily a Bluetooth mobile-app label maker.

Which one is more portable around the house?

P-touch CUBE is smaller and uses AAA batteries or an AC adapter. P-touch CUBE Plus is still compact, but it is larger and heavier while adding a built-in Li-ion battery and USB charging.

Should I choose by label width first?

Usually yes. Wider 18mm and 24mm labels are the main reason to step up to P-touch CUBE Plus. If 12mm labels are enough for pantry bins, folders, drawers, and craft storage, P-touch CUBE can be the cleaner buy.
